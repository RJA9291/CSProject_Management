# E-HAZOP Documentary: Basic Concept of E-HAZOP

**METE1153-51 Occupational Safety for Energy System · Individual Assignment 4**
Abdul Rahman bin Japry · MET264016

A cinematic technical documentary explaining the basic concept of **Electrical Hazard and Operability Study (E-HAZOP)**.
It is 1920 × 1080, 30 fps, about 3½ minutes long, with British English narration. It is built with **React + Remotion + TypeScript**
and mastered with **FFmpeg**.


`export REMOTION_BROWSER_EXECUTABLE=/path/to/chrome-headless-shell`.

### Replacing the narration with your own voice
1. Record each line from `output/narration_script.txt` as `public/audio/vo/<id>.wav` (ids `s1_1` … `s7_3` in `src/data/narration.json`).
2. `python scripts/generate_vo.py --measure-only`, then `npm run timeline`, `python scripts/generate_audio.py` and `npm run docs`.
3. `npm run build`.

To regenerate the TTS voice (Kokoro, `bm_george`, British English):
```bash
PHONEMIZER_ESPEAK_LIBRARY=/usr/lib/x86_64-linux-gnu/libespeak-ng.so.1 \
  python scripts/generate_vo.py --model kokoro-v1.0.onnx --voices voices-v1.0.bin
```

## Technical accuracy notes
- E-HAZOP is presented as structured HAZOP principles applied to electrical systems. It is a systematic, multidisciplinary
  study, not an equipment inspection, and it is distinct from process HAZOP.
- Guideword + parameter = deviation. For each deviation the team looks at causes, consequences, existing safeguards and
  recommendations, recorded in a hazard register.
- The video does not claim zero accidents ("E-HAZOP reduces risk. It does not guarantee zero incidents.").
- The transformer overvoltage case is labelled as an illustrative scenario.
- IEC 61882:2016 is cited as the reference for the HAZOP method. SAFAN, SYSOP and OPTAN appear only in a reference title,
  not as mandatory stages.
